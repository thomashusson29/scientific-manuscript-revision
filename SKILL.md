# Scientific manuscript revision

**Revise** produces submission files and an internal audit. **Audit** scores existing files in read-only mode. Assign frontier models to scientific judgment and smaller models to straightforward comments. Report whether independent review was available.

## Freeze the rubric

Before drafting or reading an existing response, have a frontier agent read the journal and article-type instructions, editorial decision, reviews and attachments. Build a journal-specific rubric totaling 20. Example weights: coverage 6, evidence 5, interpretation 4, consistency and traceability 3, clarity 2.

For each request, record the evidence needed for full credit, where it belongs and what warrants a deduction. A second frontier agent challenges the hardest cases. Date and freeze the rubric, including separate criteria for the editor and fidelity to the original.

## Resolve each comment

A fidelity reviewer reads the submitted version and records its question, methods, primary result, uncertainty and defensible conclusion. A separate frontier agent directs revisions.

- If the paper already answers a question, quote the existing passage in the letter.
- If readers need a correction, edit the smallest sufficient passage. A request to shorten the opening paragraph applies to that paragraph.
- Check disputed claims against the data or primary literature. A documented disagreement or unavailable variable can earn full credit when the reply explains the consequence. Reproduce additional analyses and label post hoc work.

## Deliver and score

In the submission language, answer the editor and each numbered comment in order. Give the decision, evidence, exact quotation and location of each change. Highlight major scientific edits in yellow. Include matching supplements, figures and analysis code as applicable, plus any clean or tracked version the journal requires. Verify quotations, numbers and highlighting in the native files.

Fresh frontier graders read the original reviews and frozen rubric first, then the revised manuscript, letter and supporting files. Withhold drafting history and earlier scores. Score each reviewer, the editor and fidelity separately. Cite evidence for each deduction and explain what would resolve it.

Aim for 20/20, with a minimum of 19 on each assessment. In revise mode, address actionable deductions and regrade the final files. Rank passing candidates by the average of fidelity and mean reviewer score. In unresolved conflicts, preserve the evidence-supported message. Report actual scores and identify what earned credit for each reviewer: the letter, a manuscript change, a supplement or a combination.
